# NubiSync Legal Overview

This file is a project guide. It is not a substitute for the controlling license text or professional legal advice.

## 1. Software license

Unless a file or third-party component states otherwise, NubiSync source code is made available under the **PolyForm Noncommercial License 1.0.0** in `LICENSE`.

The text in `LICENSE` is intentionally kept as the unmodified official PolyForm text.

If another project file conflicts with `LICENSE` about rights granted under that license, `LICENSE` controls for software covered by it.

## 2. Source-available, not OSI open source

Because PolyForm Noncommercial restricts use to permitted noncommercial purposes, NubiSync is described as **source-available** rather than OSI-approved open-source software.

## 3. Commercial licensing

The public repository does not itself grant a general commercial-use license.

Separate commercial permission may be offered by a rights holder under a distinct written agreement. See `COMMERCIAL-LICENSING.md`.

## 4. Branding

Copyright permission to use code does not automatically include permission to present a fork or modified distribution as an official NubiSync product.

See `TRADEMARKS.md`.

## 5. Privacy and telemetry

Official NubiSync builds and services are expected to follow `PRIVACY.md` and `TELEMETRY.md`.

Those files describe data-handling commitments and production-readiness gates; they are not a substitute for obligations imposed by applicable privacy law or provider policies.

## 6. Google APIs

The first provider is Google Drive.

Public production use of Google restricted scopes requires compliance with the applicable Google API Services User Data Policy, OAuth verification requirements and Drive API rules.

Development code must not be treated as authorization to bypass those requirements.

## 7. Third-party software

Dependencies and incorporated third-party material retain their own licenses.

The NubiSync license does not relicense third-party code unless the applicable rights holder has legally allowed that relicensing.

A third-party notice inventory should be generated and reviewed before binary releases.

## 8. Contributions

External copyright ownership can affect future relicensing.

Before routinely accepting substantive third-party code, NubiSync must adopt a contributor-rights mechanism appropriate to its intended licensing model.

See `CONTRIBUTING.md` and `docs/LEGAL-READINESS.md`.

## 9. No modification of the PolyForm text

Project-specific conditions must not be inserted into or presented as part of the PolyForm Noncommercial License text.

Additional project policies belong in separate files.
