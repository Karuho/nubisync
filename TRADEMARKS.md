# NubiSync Name and Branding Policy

The software license and project branding are separate.

`LICENSE` grants copyright and patent permissions only to the extent stated there. It does not grant a right to represent a modified build, fork, service or product as an official NubiSync release.

## Project identifiers

The names **NubiSync** and **DynaDev**, NubiSync logos, release artwork and other distinctive project branding may function as project identifiers.

Nothing in this document claims that any name or logo is a registered trademark in any jurisdiction.

## Permitted descriptive use

You may truthfully state that software:

- is based on NubiSync
- is compatible with NubiSync
- is a fork of NubiSync
- contains code originating from the NubiSync project

Such use must not imply sponsorship, endorsement, certification or official status when none exists.

## Forks and modified distributions

Forks and materially modified redistributions should use a name and branding that are reasonably distinguishable from official NubiSync releases.

They may retain legally required copyright, attribution and license notices.

They must not present themselves as an official NubiSync build unless the project rights holder has expressly authorized that representation.

## No endorsement

Use of NubiSync code does not create an endorsement, partnership, agency or affiliation with the NubiSync maintainers or DynaDev.

## Future policy

The project may adopt a more detailed branding or trademark policy as the product matures. Any future policy must not retroactively remove rights already granted under applicable copyright licenses.
