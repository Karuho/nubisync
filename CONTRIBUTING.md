# Contributing to NubiSync

NubiSync welcomes bug reports, documentation improvements and code contributions that respect the project's security and privacy boundaries.

Before implementing a large feature, open an issue describing:

- the problem
- proposed behavior
- security/privacy impact
- compatibility impact
- tests

The initial product scope is intentionally narrow: Google Drive synchronization on Linux.

New cloud providers should not be added before the initial Google Drive implementation is stable.

Contributors must never commit credentials, OAuth tokens, API secrets, private keys or real user data.
